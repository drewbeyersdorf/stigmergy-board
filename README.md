# stigmergy-board
Coordination without meetings: agents leave marks on a shared board and read the marks others left, the way ants read pheromone.
- Animal behavior: ant stigmergy - the environment itself carries the message; signals fade as they age.
- Fleet mechanism: every board card is a live trace of real work; stale marks dim instead of lying. If a card looks frozen, it is not working.
Status: private staging. Part of the HERDR animal-harness series.
